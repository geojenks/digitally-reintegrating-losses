Try it: mark losses and preview stitch fills

Digitally Reintegrating Losses in Heritage Embroidery · GCH 2026

Upload a photograph of an embroidery (or use the sample) and mark the loss regions as layers with the box, brush or magic-wand tools. Each layer has a stitch (French knot, satin, silk purl, or your own), a colour and a few shape settings, so a cream satin patch and black satin detail lines can be two layers. Quantise by colours splits the image into flat colour areas to start from. Preview fill shows a quick procedural stand-in texture computed in your browser. The real generative fill runs in the Colab notebook or on your own GPU, from the job bundle (.zip) you export here. For other stitches, train your own stitch LoRA and add it as a custom stitch. Nothing is uploaded: everything stays in your browser.

2. Layers

    Click a layer to select it; the tools paint into it. Higher layers win where layers overlap. Layers set to None are not exported. Hidden layers are still exported.

    4. Quantise by colours

    Splits the image into flat colour areas, one new layer each. Then pick a stitch for each layer.

    To quantise just a loss, mark it as a layer first, choose it under “Only inside layer”, then set that layer to None or delete it.

    5. Custom stitches

    For a stitch LoRA you trained yourself.

      Saved as loras/<file> in the job. Put the .safetensors file in a loras folder in the bundle, or upload it alongside the zip in Colab. It must suit the model it runs on (a FLUX LoRA for flux_base).

      6. Procedural preview

      Each layer's colour and shape settings are in section 2.

      7. Export

      Variants: 0 = one fill per region; more saves extra fills to choose between.

      Colab: choose Runtime → Run all, and pick the zip when asked.

      Locally: python pipeline/staged_reintegrate.py --job <file>.zip --model flux_base --lora_variant trigonly_v2, or drop zips in a folder and run python pipeline/run_jobs.py <folder>.

      Per-stitch masks are binary PNGs (white = selected) named <stem>__<stitch>.png, one per stitch in use.
